# Employee Leave Management System

A simple Employee Leave Management System developed using Java 17, Spring Boot, Spring Data JPA, MySQL, HTML, and JavaScript (Fetch API).

This project demonstrates a role-based Leave Management workflow where Employees can apply for leave, Managers can approve/reject leave requests, and the CEO can monitor employees and leave records.

## Technologies Used

- Java 17
- Spring Boot 3.x
- Spring Data JPA
- MySQL
- Maven
- REST API
- HTML
- JavaScript (Fetch API)
- Eclipse IDE

# Features

## User Module

- Employee Registration
- User Login
- View User Details
- Update User
- Delete User

## Employee Module

- Apply Leave
- View My Leaves
- Cancel Leave
- Logout

## Manager Module

- View Pending Leave Requests
- Approve Leave
- Reject Leave
- Logout

## CEO Module

- View All Employees
- View All Leave Requests
- Logout
