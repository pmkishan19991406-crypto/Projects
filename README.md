# Student Management System REST API

## Project Overview
The Student Management System is a RESTful CRUD application developed using Spring Boot. It provides APIs to create, retrieve, update, delete, and manage student records stored in a MySQL database. The application follows a layered architecture using Controller, Service, and Repository components and is tested using Postman.

## Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA (Hibernate)
- MySQL Database
- Maven
- Eclipse IDE
- Postman

## Features
- Create Student Record
- Retrieve Student by ID
- Retrieve All Students
- Update Student Details
- Delete Student Record
- Insert Multiple Students
- Count Total Records
- Check Student Record Exists
- RESTful API Design
- MySQL Database Integration
